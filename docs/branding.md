# KEMS branding

KEMS includes two levels of branding:

- `custom_components/kems/brand/icon.png` — compact square integration icon for Home Assistant and HACS.
- `custom_components/kems/brand/logo.png` — clean horizontal KEMS wordmark.
- `docs/assets/kems_full_brand_concept.png` — full energy-system concept combining home, solar, battery, EV charging, and managed energy flow.

The compact icon and wordmark are preferred inside Home Assistant because they remain clear at small sizes. The full concept is intended for project documentation, GitHub social imagery, banners, and presentation material.
