# Roadmap

## 0.3 — Observe / Learn / Advise / Simulate

- Automatic source discovery
- Persistent observations
- Rolling profiles and confidence
- Explainable advice
- Battery/tariff replay simulation
- No hardware control

## Before Control

- Validate entity discovery on the live Octopus, Ohme, and FoxESS installations
- Compare simulation with actual operation over multiple weeks
- Add solar and load forecasts
- Add mission planning and audit history
- Define safety invariants and fail-safe behaviour
- Require explicit opt-in and a global kill switch

## Future providers

Provider adapters can later add other tariffs, chargers, inverters, batteries, smart meters, and solar forecast services without changing the core engines.
